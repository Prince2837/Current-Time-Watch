# ⏰ Show Current Time on Screen

A simple web application that displays the **current system time in real-time** using **HTML, CSS, and JavaScript**.  
The clock updates every second and shows hours, minutes, and seconds in a clean digital format.

---<br>
<br>
## 🚀 Features
- Displays current time in real-time <br>
- Updates every second<br>
- Clean and responsive UI<br>
- Lightweight and fast<br>

---<br>

## 🛠️ Technologies Used
- HTML  <br>
- CSS3  <br>
- JavaScript (Vanilla JS) <br>
